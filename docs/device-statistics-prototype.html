关于这些数字 · 数据口径说明

活跃时长按心跳间隔累计（默认每次 30 秒），丢包不计入，存在采样误差。仅统计活跃时的前台应用，不能等同于设备在线时长或工作时长。

有记录日均 = 已记录活跃时长 ÷ 有记录天数（含已记录为 0 的日期）。缺失日期标记“无记录”，不推断为零活跃；当前 API 通常不会返回零值日期，此状态仅作原型演示。今天标为“进行中”，累计与日均均包含今天已记录的部分。所有日期按 Asia/Shanghai 分组。

此原型使用固定演示日期 2026-09-19，样例覆盖 2026-08-01 至 2026-09-19。没有连接真实设备或保存密钥。历史详情只展示每日应用聚合，不展示历史逐小时数据。
